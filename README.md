# FridgeQuest

![FridgeQuest System Architecture](Download.png)

Your food has a story.

FridgeQuest ist eine mobile FoodTech-Anwendung, die Lebensmittelbestand,
spielerische Charaktere, nachhaltigen Konsum und KI-gestützte Küchenplanung
verbindet.

## Aktueller Stand

Das Repository enthält zunächst nur das Flutter-Projekt und die zentrale
Produktdokumentation. Backend, Datenbank, Cloud und AI-Komponenten folgen in
späteren Phasen.

## Struktur

- `mobile/` – Flutter-App
- `docs/` – Produkt-, Design-, Architektur- und Entscheidungsdokumentation

## Lokal starten

```bash
cd mobile
flutter pub get
flutter run
```

## Dokumentation

Der bestätigte Produktplan liegt unter [`docs/PRODUCT_PLAN.md`](docs/PRODUCT_PLAN.md).
